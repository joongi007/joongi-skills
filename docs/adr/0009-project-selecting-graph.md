# ADR-0009: 공용 코드 그래프의 명시적 프로젝트 선택

상태: accepted · 날짜: 2026-11-10

## 맥락

공용 MCP를 특정 저장소의 `--repo`와 `CRG_DATA_DIR`로 등록하면 다른 프로젝트의 에이전트도
같은 그래프를 사용하게 된다. 경로 인자만 바꾸면 원본 서버가 그래프 출처 불일치로 거절한다.
불일치 검사는 올바른 보호 동작이며 제거하지 않는다.

## 선택

공용 연결은 별도 어댑터를 통해 모든 분석 도구의 `repo_root`를 필수로 받는다.
프로젝트 경로별로 DB·설정 홈·원본 MCP 프로세스를 분리하며, 저장된 경로가 같은
실제 디렉터리인지 확인한다. 캐시 키에는 재부팅 때 바뀔 수 있는 mount ID를 쓰지 않는다. 현재 작업 디렉터리나 마지막 선택을 기본으로 삼지 않는다.
한 프로젝트의 색인을 다른 프로젝트 경로로 다시 빌드하지 않는다.

색인은 `graph_build`로 명시적으로 시작하고 `graph_project_status`로 진행을 조회한다.
2개 빌드·5분 제한, 프로세스당 최대 2개 분석 연결로 리소스를 제한한다.
Git/SVN이 없는 프로젝트의 표지 생성만 별도 boolean으로 명시하게 한다.
원본의 분석 도구 7개와 기존 입력 형식은 보존하며 임의 코드 실행·refactor 적용은 추가하지 않는다.

프로젝트 고정 연결은 도우미의 `--fixed-project`로만 선택한다. 기존 DB는 자동 변경하지 않는다.

## 검증

실제 서버에서 A의 통계는 성공하고 B 경로로 같은 DB를 조회하면 출처 불일치로 거절됨을 재현했다.
회귀 테스트와 실제 Python·TypeScript 두 저장소의 A→B→A 조회로 분리를 확인한다.
[운영 문서](../operations/04-code-review-graph.md)에 사용 흐름과 제한을 기록한다.
