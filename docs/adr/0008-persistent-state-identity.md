# ADR-0008: 연결 방식과 독립된 영구 등록 저장소

상태: accepted · 날짜: 2026-11-10

검토용 웹은 `/tmp`의 상태를 사용했지만 공용 설치는 새 사용자 홈 상태를 열었다.
검토용 파일 소실과 설치 시 이관 누락을 정상적인 빈 목록과 구분할 정보가 부족했다.

설치된 런처의 기본 상태 경로를 설치 사용자 홈에 고정하고, 명시적 `--state-dir`만 다른 저장소를
선택하게 한다. 소스 실행의 환경 변수 설정은 유지한다. CLI·MCP·웹에서 경로와 임시 저장소 여부를
확인할 수 있게 한다. 등록 변경을 프로세스 간 잠금으로 보호하고 마지막 목록을 백업한다.
백업이 있는데 원본이 없으면 조용히 빈 목록으로 처리하지 않는다.

이관은 원본 보존·충돌 시 전체 중단·임시 실행 환경 거절을 따르는 명시적 서버 설정 병합이다.
인증·Tasks·프로젝트의 자동 복제나 서로 다른 OS의 데이터 폴더 공유는 하지 않는다.
자세한 절차와 보장 범위는 [운영 문서](../operations/07-state-consistency.md)를 따른다.
