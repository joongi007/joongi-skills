# ADR-0003: manifest 기반 설치

상태: accepted · 날짜: 2026-11-05

## 맥락

여러 에이전트에 설치·업데이트·제거하되 사용자의 다른 스킬과 MCP 설정을 보존해야 한다.
새 에이전트는 다음 설치·업데이트 시 발견할 수 있어야 한다.

## 결정

감지된 agent와 명시적으로 선택한 agent를 구분하고 dry run을 제공한다.
설치한 파일·등록 항목과 hash를 manifest로 추적한다. 소유하지 않은 파일은 덮어쓰지 않고
설치 후 사용자가 수정한 파일은 갱신·제거에서 보존하며 충돌을 보고한다.
설정 전체를 교체하지 않고 Hub가 관리하는 등록만 수정한다.
GitHub Pages는 공개 다운로드·명령 안내를 제공하고 사용자가 터미널에서 실행한다.

## 대안과 결과

전체 설정 복사는 단순하지만 기존 MCP와 사용자 설정을 잃을 수 있다.
symlink만 배포하면 원본 삭제·이동과 Windows 지원에 제약이 있다.
manifest 방식은 충돌 처리·이전 상태 복구 테스트가 필요하지만 소유권 경계가 명확하다.
클라이언트 설정 형식이 바뀌면 agent adapter와 공식 출처를 함께 갱신한다.

## 검증

임시 HOME에서 첫 설치·재설치·새 agent 발견·업데이트·수정 파일 충돌·제거를 확인한다.
파일 바깥을 가리키는 symlink나 malformed config를 안전하게 거절하는지 검증한다.
