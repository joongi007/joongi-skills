# ADR-0007: 명시적 연결 방식과 선택적 웹 실행

상태: accepted · 날짜: 2026-11-08

## 맥락

개인 에이전트는 별도 상주 서버 없이 사용할 수 있어야 하고, 여러 에이전트에서 공유할 사용자는
HTTP Hub를 선택할 수 있어야 한다. 실행 중인 서버의 유무만으로 연결 의미를 조용히 바꾸지 않는다.

## 선택

기본을 순수 stdio로 변경하고 `hybrid`, `http`를 명시적 설정으로 제공한다. 공용 기본과 프로젝트
재정의를 같은 상태 저장소 안에 두며 CLI 인자가 저장값보다 우선한다. 기본값 변경으로 기존
자동 공유를 계속 쓰려는 사용자는 혼합 모드를 선택해야 한다.

혼합 모드는 시작 시에만 저장소 hash·인스턴스를 health로 확인하고 연결을 고정한다.
도구 호출 전송 뒤에는 다른 방식에서 재실행하지 않는다. HTTP 프로젝트 URL은 범위를 고정하고
metadata·header·session의 충돌을 거절한다. 인증 파일은 독립 프로세스 간 OS 잠금으로 보호한다.

설치기와 웹은 에이전트별 native 형식을 공유한다. 웹은 스킬 설치와 MCP 등록 계획을 분리하고
기존 installer의 소유권·잠금·복구를 재사용한다. WSL은 인자 배열로 Windows용 설정을 생성한다.
개인 설정 자동 변경은 사용자가 검토한 계획 적용 또는 명시적 설치 명령에서 수행한다.

웹 UI의 상주 실행은 선택 사항으로 `start/stop/restart/status/open`을 제공한다. 종료는 health에서
확인한 실행 인스턴스의 보호된 관리 API로 요청하며 임의 PID에 신호를 보내지 않는다.
Docker·k3s·원격 공개·호출 중 자동 전환·자동 유휴 종료는 이번 결정에 포함하지 않는다.

## 대안·결과

에이전트에 stdio와 HTTP를 별도 이름으로 동시에 등록하는 방식은 도구 중복·상태 혼동 때문에
기본 경로로 쓰지 않는다. 연결 방식을 바꿀 때 데이터 폴더를 나누는 방식도 선택하지 않는다.
동시 독립 stdio는 각각 upstream 프로세스를 가질 수 있다. 공유·리소스 절약이 필요하면 혼합 또는
HTTP를 선택한다. 웹 탭을 닫아도 HTTP Hub가 종료되지는 않는다.

## 검증

`tests/test_connections.py`, `tests/test_credential_lock.py`는 모드 선택·실제 stdio/HTTP·범위·
설정 보존·여섯 에이전트 형식·등록 보호·daemon 수명주기·프로세스 간 인증 잠금을 검증한다.
`tests/browser_connections.cjs`는 웹 모드 선택과 공용·프로젝트 등록·WSL 설정·모바일을 검증한다.
기존 OAuth·Apps·Tasks·공식 SDK 상호 운용도 회귀 검증한다.
