# 로컬 프로젝트의 MCP·스킬 수집

프로젝트 폴더에서 MCP 설정과 `SKILL.md`의 출처를 찾아 로컬 카탈로그로 모은다.
다른 프로젝트의 파일은 변경하지 않는다.

```bash
python3 scripts/collect_local_integrations.py --root /mnt/d/Project
```

기본 출력은 `.local/integrations/catalog.md`와 `catalog.json`이다.
`.local/`은 git 추적 대상과 Pages 소스 번들에서 제외한다. 개인 경로·프로젝트 이름을
공개 문서에 복사하지 않는다. `--out`으로 출력 폴더를 지정할 수 있지만,
개인 목록은 공개 배포 경로 밖에 둔다.

스킬은 이름·원본 경로·SHA-256을 수집하고 내용이 같은 사본을 묶는다.
본문·참조·설명은 복제하지 않는다. MCP는 이름·전송 방식·활성 설정·원본 경로만 모은다.
실행 명령, 인자, URL, 환경변수와 헤더는 출력하지 않는다. 이름이나 경로 자체에도
개인 정보가 있을 수 있으므로 목록은 로컬에 보관한다.

## 탐색 범위

- `.mcp.json`, `mcp.json`, `mcp_config.json`, `claude_desktop_config.json`,
  `settings.json`, `settings.local.json`, `opencode.json`, `opencode.jsonc`, `config.toml`.
- JSON/JSONC의 `mcpServers`, `mcp_servers`, `mcp`, VS Code의 `servers` 컨테이너.
- Codex TOML은 Python 3.11 이상에서 파싱한다. Python 3.10에서는 해당 파일을 오류 목록에 남긴다.
- 의존성·빌드·가상환경·캐시·검증용 임시 사본은 제외하고 심볼릭 링크는 따라가지 않는다.
- 탐색 깊이 12, 파일 100,000개, 파일당 1 MiB로 제한한다. 제한과 읽기 오류는 JSON에 기록한다.
  파일 수 제한에 도달하면 종료 코드 2와 함께 부분 결과를 남긴다.

카탈로그는 **설정에서 발견한 후보**다. 연결 성공·실제 사용·MCP Apps/Tasks/Skills 기능을
검증한 목록이 아니다. 코드에서 동적으로 생성하는 MCP나 사용자 홈의 전역 설정은 이 탐색에
포함되지 않는다. 필요하면 범위를 정해 별도로 조사한다.

## Hub와 공용 스킬로 재사용

원본 경로에서 지침·라이선스·프로젝트 의존성을 먼저 확인한다.
공용 도입 대상은 여러 프로젝트에서 독립적으로 쓸 수 있는 스킬이다.
특정 앱의 실행 환경·전용 API·데이터에 의존하는 스킬은 원본 프로젝트에서 유지하고
공용 설치·업데이트·배포 대상에서 제외한다. 카탈로그에 발견됐다는 이유로 도입하지 않는다.
범용으로 재사용할 필요가 확인된 경우에만 프로젝트 고유 부분을 분리해
`skills/`의 독립 패키지로 작성한다.

재사용할 MCP는 로컬 UI에 필요한 환경에 맞춰 등록한 뒤 **연결 확인**으로 기능을 확인한다.
카탈로그 수집은 서버를 실행하거나 Hub에 자동 등록하지 않는다. 인증값은 공개 스킬이나
카탈로그에 옮기지 않고 해당 실행 환경의 비밀 설정으로 제공한다.
