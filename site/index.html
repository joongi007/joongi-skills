작동 방식

연결은 한 곳에.
지식은 필요한 만큼.

같은 지침과 MCP 연결을 한 곳에서 관리합니다.
도구 설명을 읽는 범위는 에이전트마다 다릅니다.

  1. 01

    내 에이전트를 연결합니다

    설치 도구가 기존 에이전트 디렉터리를 감지합니다. 적용할 대상을 직접 지정하거나, 변경 내용을 먼저 확인할 수 있습니다.

  2. 02

    스킬과 MCP를 모읍니다

    한국어·개발·디자인 스킬 3개를 함께 설치합니다. 외부 MCP는 관리 화면에서 직접 등록하고 연결을 확인합니다.

  3. 03

    찾고, 읽고, 실행합니다

    필요한 스킬과 도구를 검색합니다. 상세 지침을 읽고, 실행 상태와 결과를 같은 작업 공간에서 확인합니다.

클론한 저장소에서 설치하기

GitHub 저장소를 클론한 뒤 저장소 루트에서 실행하세요. 아래는 Bash 명령이며, Windows는 PowerShell 안내를 따르세요.

bash install.sh install --dry-run
bash install.sh install

특정 에이전트만 설치하려면:

bash install.sh install --agent codex

설치 후 에이전트의 MCP 연결을 다시 열고 “Hub에서 usual-korean 스킬을 찾아 읽어줘”라고 요청하세요. 기본은 stdio라 웹을 미리 켤 필요가 없습니다.

설치 전 변경 확인--dry-run을 붙여 실행하세요.

관리 화면 열기

등록된 연결과 스킬, 실행 상태를 확인합니다.

joongi-hub open

업데이트

이 페이지에서 설치했다면 최신 배포본을 받습니다. 새 에이전트도 감지합니다.

joongi-skills update

웹 서버 끄기

관리 화면이 필요 없을 때 종료합니다. 기본 stdio 연결은 계속 사용할 수 있습니다.

joongi-hub stop

설치 상태 확인

관리 대상과 변경된 파일을 확인합니다.

joongi-skills status

제거

이 도구가 관리하는 파일을 제거합니다. 직접 수정한 파일은 보존됩니다.

joongi-skills uninstall

명령은 ~/.local/bin에 설치됩니다. PATH에 없다면 전체 경로를 사용하세요. Windows는 & "$HOME/.local/bin/joongi-skills.cmd" update 형식입니다. 클론 설치는 git pull --ff-only 후 업데이트하세요. OS별 전체 명령 보기
