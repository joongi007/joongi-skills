첫 사용·외부 MCP 연결 안내 →

지침은 스킬로,
실행은 MCP로.

스킬은 에이전트가 읽는 작업 지침입니다. MCP는 에이전트가 외부 도구를 호출하는 연결 방식입니다.

기본 stdio 방식은 에이전트가 Hub를 실행합니다. 관리 화면은 필요한 때만 열 수 있습니다.

  1. 01

    기존 에이전트에 등록

    Claude Code·Codex·Cursor·Copilot CLI·Gemini CLI·OpenCode의 설정 폴더를 감지합니다. 에이전트 앱 자체를 설치하지는 않습니다.

  2. 02

    외부 MCP는 직접 추가

    처음 설치하면 외부 서버 목록은 비어 있습니다. 서버를 등록한 뒤 연결하고, 필요한 서비스에 로그인하세요.

  3. 03

    필요한 것부터 검색

    스킬·등록된 MCP·연결된 도구를 함께 검색합니다. 선택한 지침과 도구의 상세 정보를 읽고 사용합니다.

함께 설치되는 스킬 5개

필요한 작업에서 선택해 읽습니다. 파일 설치만으로 모든 에이전트의 자동 적용을 보장하지는 않습니다.

다이어그램 · 아이콘

“서비스 구조를 그림으로 정리해줘.”

Git 문서에는 Mermaid, 직접 편집할 그림에는 Excalidraw, 정밀한 배치에는 SVG를 검토합니다. 원본과 실제 렌더 결과를 함께 확인합니다.

다이어그램·아이콘 제작 방법 →
  1. 목적에 맞게 선택읽는 사람, 편집 방식, 사용할 크기 확인
  2. 같은 디자인 적용creating-diagrams프로젝트 토큰으로 도형·텍스트·아이콘 구성
  3. 렌더하고 검토글자·연결·잘림 확인 후 원본과 이미지 전달

제작 지침을 제공합니다. Excalidraw 편집기와 외부 렌더 엔진은 별도로 준비합니다.

01 / 3D

“이 의자 사진을 3D로 만들어줘.”

이미지를 분석하고, 한 단계씩 렌더를 비교합니다. 스킬이 작업 순서를 안내하고 MCP가 누락된 검토 기록을 찾습니다.

작업 절차와 검사 범위 보기 →
  1. 찾고 읽기building-procedural-3d참조·구성요소·특징·성능 예산 정리
  2. 만들고 비교하기blockout → 형태 → 재질 → 상호작용 → 최적화
  3. 검사하고 수정하기hub_3d_review증거 누락은 blocked · 보완 후 다시 검사
에이전트의 도구 사용 예시
hub_search(query="building-procedural-3d", kind="skill")
hub_read_skill(name="building-procedural-3d")
hub_3d_review(target_stage="blockout", report=...)

검사 대상은 제출 기록입니다. 실제 렌더·시각적 유사도는 별도 검토하며 원본 img2threejs 엔진을 실행하는 기능은 아닙니다.

02 / MCP

“Notion 페이지를 읽고 요약해줘.”

등록·로그인을 확인한 뒤 읽기 요청을 검토합니다. 지원하는 GUI 앱에서는 앱 안에서, 그 외에는 로컬 승인함에서 선택합니다.

호스트별 승인 조건 보기 →
  1. 연결 확인hub_connect(server="notion")필요하면 사용자가 OAuth 로그인
  2. 실행 전 승인도구·인수·연결 주소를 확인하고 이번 호출 선택
  3. 실행하고 전달수락한 요청만 실행 · 거절·취소하면 실행하지 않음
앱 안에서 승인하려면?

2025-11-25 stdio와 form elicitation을 지원하는 호스트에서 사용할 수 있습니다. 일반 MCP Apps의 화면 지원과는 별개이며, 미지원 환경은 브라우저 승인함을 사용합니다.

필요할 때 열고,
갱신하고, 정리하세요.

아래는 macOS·Linux·WSL의 전체 경로 명령입니다. 새 에이전트는 업데이트할 때 다시 감지합니다.

Windows 관리 명령 →

관리 화면 열기

연결·인증·스킬을 관리합니다. 에이전트에게 “Hub 설정 화면 열어줘”라고 요청해도 됩니다.

~/.local/bin/joongi-hub open

업데이트

원격 설치는 최신 배포본을 받습니다. 클론 설치는 저장소에서 git pull --ff-only 후 실행하세요.

~/.local/bin/joongi-skills update

상태 확인

설치 대상과 변경된 파일을 확인합니다.

~/.local/bin/joongi-skills status

관리 웹 서버 끄기

open으로 실행한 웹을 중지합니다. 기본 stdio 연결과는 별도입니다.

~/.local/bin/joongi-hub stop

제거

관리 중인 설치 파일을 제거합니다. 사용자 수정본과 연결·인증 상태는 보존합니다.

~/.local/bin/joongi-skills uninstall

연결 전에 확인하세요.

외부 stdio MCP는 격리 실행 환경이 필요합니다. 서비스 인증·Apps·Tasks는 서버와 에이전트의 지원 범위에 따라 달라집니다.
