# 기술 삽화와 아이콘

## anatomy식 기술 삽화

[anatomy](https://github.com/wheresryan22/anatomy)는 등각투영 SVG와 선택적 WebGL을 사용하는 스킬이다.
전체 kit·예제·3D 엔진은 이 스킬에 포함하지 않는다. 물리 구조·부품 간 연결을 설명할 때 다음 접근을 참고한다.

- 실제 구조와 설명용 은유를 구분한다. 시스템을 기계처럼 그렸다면 그 비유의 범위를 밝힌다.
- 투영축·광원·깊이 순서를 통일하고 주요 부품부터 만든다. 연결·작동 설명에 필요한 부품만 추가한다.
- 분해도는 원래 조립 위치와 연결이 추적되게 한다. 애니메이션 수치와 읽기값은 같은 모델에서 계산한다.
- 상호작용은 키보드·초기화·정적 대체와 reduced-motion을 고려한다. 설명에 도움이 없다면 정적 SVG로 끝낸다.
- 과학적 구조·성능 수치는 출처를 확인한다. 시각적으로 그럴듯함을 물리 검증으로 설명하지 않는다.

## 앱·웹 아이콘

다이어그램 스킬과 아이콘 제작은 목적이 다르다. diagram-design이 앱 아이콘 전용 도구라고 설명하지 않는다.

- 기존 제품 icon set을 먼저 재사용한다. 새 아이콘은 grid·viewBox·stroke·모서리·optical size를 통일한다.
- 웹 UI 아이콘은 실제 16/20/24/32px 등 사용하는 크기로 확인하고, 작은 크기에서는 디테일을 줄인다.
  가는 선·빈 공간·선명도와 light/dark 배경을 확인한다. 장식 아이콘과 동작 버튼의 접근성 이름을 구분한다.
- 앱 아이콘은 대상 플랫폼의 현재 규격·마스크·safe area·투명도·필요 크기를 공식 문서로 확인한다.
  favicon, PWA icon, Apple/Android 런처 아이콘을 같은 파일 하나로 충족했다고 가정하지 않는다.
- 손으로 편집할 벡터는 SVG 원본과 크기별 PNG를, 사진·복잡한 질감이 필요한 경우에는 사용 가능한
  이미지 생성 도구를 선택한다. 상표·외부 폰트·아이콘의 사용 권한은 각각 확인한다.
- 결과는 목표 크기의 실제 렌더, 원본, export 크기 목록으로 전달한다. 확대 미리보기만으로 검수하지 않는다.
